A two-line explanation for a 10-year-old: a queue is a train with no engine, every person a carriage hitched to the one ahead, nobody moving until the front carriage rolls away — and an honest second line about what the train maps (movement only from the front, one at a time, in order) and what it leaves out (real people can step out, swap places, or walk away, and carriages never can). The program writes those two lines to `entry.txt`, nothing more.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
